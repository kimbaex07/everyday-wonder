One sentence about a small moment of wonder in everyday life, written for the [make.fun bounty](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3) ($2 prize pool, closes 26 Nov 2026 18:35 WIB).

> The escalator handrail outruns its own steps, so my hand keeps arriving a little ahead of me.

The wonder is in the mismatch: hand and body ride the same machine, yet the hand keeps getting there first. In practice the handrail belt is driven a touch faster than the step chain, so if you hold on loosely your palm glides forward and you keep re-gripping — a tiny, daily reminder that even a machine built to move as one body cannot quite agree with itself. The sentence stays grounded in that real, checkable detail instead of dressing the moment up: no metaphor is needed, because the escalator is already doing something strange.

`main.py` writes the sentence to `entry.txt` (93 characters, deterministic, Python stdlib only).

## Run it

```bash
python3 main.py
```

By default it writes to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to choose another directory.
